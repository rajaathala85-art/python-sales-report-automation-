# Python Sales Report Automation

A Python-based desktop application that converts sales CSV data into a professional Excel report automatically.

## 🚀 Features

* 📂 Select CSV sales files
* ✅ CSV data validation
* 📊 Calculate total sales
* 📦 Calculate total quantity
* 🏆 Identify the best-performing product
* 📈 Product-wise sales analysis
* 📑 Generate professional Excel reports
* 🖥️ Simple desktop GUI
* ⚠️ Error handling for invalid data

## 🛠️ Technologies

* Python
* Tkinter
* CSV
* OpenPyXL

## 📋 Input Format

The CSV file should contain these columns:

```text
product,quantity,price
Laptop,2,45000
Mouse,10,500
Keyboard,5,1200
Monitor,3,15000
```

## 📊 Generated Report

The application creates an Excel file containing:

* Sales summary
* Total quantity
* Total sales
* Best product
* Highest sale
* Average revenue per item
* Product-wise sales

## ▶️ How to Run

Clone the repository and open the project folder:

```bash
cd python-sales-report-automation
```

Install the required package:

```bash
pip install openpyxl
```

Run the application:

```bash
python app.py
```

Select your CSV file and choose where to save the generated Excel report.
